# Tasks

Manage task lifecycle.

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/tasks` | [List tasks](list/) |
| `POST` | `/api/tasks` | [Create a task](create/) |
| `GET` | `/api/tasks/{id}` | [Get a task](get/) |
| `PATCH` | `/api/tasks/{id}/complete` | [Change completion status](complete/) |
| `DELETE` | `/api/tasks/{id}` | [Delete a task](delete/) |
